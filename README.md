## 🚀 Getting Started

### Prerequisites

Install a C++ compiler, such as GCC through MinGW-w64, and a code editor such as Visual Studio Code.

### Clone the Repository

```bash
git clone https://github.com/kyush02/CPP-Projects.git
```

Navigate to the project directory:

```bash
cd CPP-Projects
```

### Compile and Run a Program

For example, to run the calculator:

```bash
g++ 01_cal.cpp -o calculator
```

On Windows, run:

```powershell
.\calculator.exe
```

To run another program, replace the source filename and executable name accordingly.
