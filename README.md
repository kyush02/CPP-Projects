# 🧮 Simple Calculator in C++

A simple, menu-driven calculator built using **C++**. This beginner-friendly project performs basic arithmetic operations through a command-line interface.

## ✨ Features

- ➕ **Addition** — Adds two integers.
- ➖ **Subtraction** — Calculates the difference between two integers.
- ✖️ **Multiplication** — Multiplies two integers.
- ➗ **Division** — Divides two numbers and displays a decimal result.
- `%` **Remainder** — Calculates the remainder using the modulus operator.
- 🚪 **Exit Option** — Enter `E` to exit the calculator.
- 🔄 **Interactive Menu** — Perform multiple calculations without restarting the program.

## 🛠️ Technologies Used

- **Language:** C++
- **Header:** `iostream`
- **Concepts:** Functions, loops, conditional statements, `switch-case`, and arithmetic operators.
- **Interface:** Command-line / terminal.

## 📋 Prerequisites

Before running the program, make sure you have:

- [Git](https://git-scm.com/downloads) installed to clone the repository.
- A C++ compiler, such as [GCC](https://gcc.gnu.org/) or [Clang](https://clang.llvm.org/).

## 🚀 Getting Started

### 1. Clone the repository

Open your terminal and run:

```bash
git clone https://github.com/kyush02/Simple-Calculator.git
```

### 2. Navigate to the project folder

```bash
cd Simple-Calculator
```

### 3. Compile the program

If you have GCC installed, run:

```bash
g++ cal.cpp -o calculator
```

### 4. Run the calculator

**Windows (Command Prompt / PowerShell):**

```powershell
.\calculator.exe
```

**Linux / macOS:**

```bash
./calculator
```

## 🎮 How to Use

1. Run the program.
2. Choose an arithmetic operation by entering its symbol.
3. Enter the first and second numbers when prompted.
4. View the result in the terminal.
5. Select another operation or enter `E` to exit.

### Example

```text
----------------------------------------
        Welcome to calculator.
----------------------------------------
Enter < + > for addition
Enter < - > for subtraction
Enter < * > for multiplication
Enter < / > for division
Enter < % > for remainder
Enter < E > for exit...
Enter your choice : +
Enter first number : 10

```
